# Statbound Cards

A browser-based, text-driven RPG where players train their character's stats, take on risky jobs for cash, and settle fights through turn-based collectible card battles. The cards a player can buy and play depend on their stats, so how you build your character decides which strategies are open to you.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
